# KAZSAFETY — COREX KAZ 003

Мобильный мини-магазин зимних защитных ботинок **COREX KAZ 003** для ИП Kazsafety (Актау).

## Возможности

- Галерея фото со свайпом, стрелками и миниатюрами
- Выбор нескольких размеров с количеством
- Заказ и вопросы менеджеру через WhatsApp (`+7 776 060-50-70`)
- Счёт для юрлиц, бесплатная доставка по Актау
- FAQ, отзывы, похожие товары, Instagram, 2GIS

## Запуск

Откройте `index.html` в браузере или локальный сервер:

```bash
npx serve -l 8765
```

Сайт: http://localhost:8765
